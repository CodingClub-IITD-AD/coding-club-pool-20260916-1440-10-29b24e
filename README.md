# Coding Club Git & GitHub Workshop

This repository belongs to one workshop team. Work on the branch named by the companion site, open a pull request, and merge through GitHub.

## Workshop files

- `mission_control.json` — spacecraft repair and escape-route exercises
- `challenge/` — safe, synthetic history exercise data
- `madlib/submissions/` — one credited JSON file per team member

Never add passwords, access tokens, or real application `.env` files.
